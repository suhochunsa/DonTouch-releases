# DonTouch-releases

AI와 함께 개발하는 2D 픽셀 샌드박스 · 서바이벌 게임의 배포용 저장소입니다.

## 🌐 공식 사이트

### ▶ [DonTouch 공식 다운로드 페이지](https://claude.ai/code/artifact/28585eef-7859-4563-a008-7a1faba50bb8)

게임 소개 + 운영체제 자동 감지 원클릭 다운로드. (아래 직접 링크로도 받을 수 있어요.)

## ⬇️ 다운로드 (항상 최신 버전)

### ▶ [최신 릴리스에서 받기](https://github.com/suhochunsa/DonTouch-releases/releases/latest)

최신 릴리스의 **Assets**에서 운영체제에 맞는 파일을 받으세요 (`<버전>`은 릴리스 번호, 예: `1.0.11`).

| 플랫폼 | 파일 |
|---|---|
| **Windows — 설치 프로그램 (권장)** | `DonTouch-<버전>-windows-setup.exe` |
| Windows — 포터블 ZIP | `DonTouch-<버전>-windows.zip` |
| **macOS — 디스크 이미지 (권장)** | `DonTouch-<버전>-macos.dmg` |
| macOS — ZIP | `DonTouch-<버전>-macos.zip` |

> [공식 다운로드 페이지](https://claude.ai/code/artifact/28585eef-7859-4563-a008-7a1faba50bb8)는 운영체제를 감지해 최신 버전 파일로 바로 연결해 줍니다. 특정 버전은 [모든 릴리스](https://github.com/suhochunsa/DonTouch-releases/releases)에서 받을 수 있어요.

## 설치 / 실행

- **Windows (설치 프로그램):** `setup.exe`를 실행하면 자동 설치 + 시작 메뉴·바탕화면 바로가기가 생깁니다 (관리자 권한 불필요). 새 버전은 게임 안에서 자동 업데이트돼요.
- **Windows (포터블 ZIP):** 압축을 풀고 `DonTouch` 폴더 안의 실행 파일을 여세요.
- **macOS:** `.dmg`를 열어 DonTouch를 응용 프로그램 폴더로 옮기세요 (`.zip`이면 압축을 풉니다). "확인되지 않은 개발자" 경고가 뜨면 앱을 우클릭 → 열기.

> 서명되지 않은 개인 빌드라 첫 실행 때 SmartScreen / Gatekeeper 경고가 뜰 수 있어요 — 정상입니다. Windows는 **추가 정보 → 실행**으로 진행하세요.
