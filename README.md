# DonTouch-releases

AI와 함께 개발하는 2D 픽셀 샌드박스 · 서바이벌 게임의 배포용 저장소입니다.

## ⬇️ 다운로드 (항상 최신 버전)

| 플랫폼 | 받기 |
|---|---|
| **Windows — 설치 프로그램 (권장)** | **[DonTouch-windows-setup.exe](https://github.com/suhochunsa/DonTouch-releases/releases/latest/download/DonTouch-windows-setup.exe)** |
| Windows — 포터블 ZIP | [DonTouch-windows.zip](https://github.com/suhochunsa/DonTouch-releases/releases/latest/download/DonTouch-windows.zip) |
| macOS | [DonTouch-macos.zip](https://github.com/suhochunsa/DonTouch-releases/releases/latest/download/DonTouch-macos.zip) |

> 위 링크는 항상 **최신 릴리스**를 받습니다. 특정 버전은 [모든 릴리스](https://github.com/suhochunsa/DonTouch-releases/releases)에서 받을 수 있어요.

## 설치 / 실행

- **Windows (설치 프로그램):** `setup.exe`를 실행하면 자동 설치 + 시작 메뉴·바탕화면 바로가기가 생깁니다 (관리자 권한 불필요). 새 버전은 게임 안에서 자동 업데이트돼요.
- **Windows (포터블 ZIP):** 압축을 풀고 `DonTouch` 폴더 안의 실행 파일을 여세요.
- **macOS:** `.zip`을 풀고, "확인되지 않은 개발자" 경고가 뜨면 앱을 우클릭 → 열기.

> 서명되지 않은 개인 빌드라 첫 실행 때 SmartScreen / Gatekeeper 경고가 뜰 수 있어요 — 정상입니다. Windows는 **추가 정보 → 실행**으로 진행하세요.
